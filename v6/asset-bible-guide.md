# Editable behavioral asset bible
Each canonical asset needs referent/role, recognition traits/forbidden confusions, silhouette/proportions, named parts/anchors/pivots, scale/units, materials/palette/surface/light response, state variants, trigger/action/response/settle, contacts/constraints, closest camera use, reuse limits, implementation/budget and rights/source/uncertainty.

Canonical asset ID differs from scene instance ID. Motion binds editable parts, not flattened plates. Dynamic heroes need meaningful state/articulation. Environmental stillness needs passive/optical/camera contribution and reason. Deliver editable geometry/vector/texture modules; never collapse FG/hero/BG/camera/light into one bitmap.

Inspect silhouette, relevant angles, closest crop, material, part/anchor behavior and extreme states. Solve a demanding representative asset before multiplication. Procedural construction is not proof. Storyboard owns meaning/geography/attention, illustration construction, motion assembly, VFX response. Preserve IDs and report limitations. Recoloring an old hero does not make an original identity.

# v5 -> v6 repository migration

This upgrade changes shared rules, prompts, packet architecture and tooling. It does not upgrade an existing film's artwork or regenerate its VO/render.

## Replaced

- Chapter/section assembly as the production hierarchy -> cross-linked meaning beats/scenes/camera shots.
- Literal noun-to-icon and forced SVG-first -> metaphor/mechanism with explicit medium choice.
- Micro-motion/particle/layout/density/glow quotas -> readable state/knowledge landmarks and motivated behavior.
- Per-section external model spec generation -> in-session direction plus deterministic offline packet compiler.
- Regex card-rule validation -> typed contracts, canonical references, supported relations, timing/media provenance, state carry and review evidence.
- Automatic renderer command suggestions -> guarded render with exact reviewed delivery binding and current authorization.

## Preserved

Existing Remotion/React/Three.js versions and old composition imports; source audio utilities; existing film output and frozen backup; valid shared primitives and deterministic timing principles. Historical rules/scripts are archived in `legacy/`; explicit legacy flags are for reproduction only.

## Added

Root AGENTS/CLAUDE/context protocol, comprehensive visual-script guide, original art/behavioral asset authoring, complete repo-local skill snapshots/hash manifest, six strict schemas/templates, packet initializer, plan/build/render validator, offline direction compiler, absolute-frame runtime, guarded rendering and synthetic enforcement tests.

## Honest boundary

No finished visual identity, fabricated asset bible or approved styleframes were created for an unspecified topic. The repo now requires and structures that work for each film. Runtime primitives are not a complete automatic filmmaker; directed assets/camera/actions/VFX still need implementation and visual review. Validation cannot detect every lie or determine artistic quality. Direct CLI/source edits can bypass wrappers; repo instructions and actual reviewers remain part of enforcement.

Meta/TikTok detailed policy pages were unavailable during research. The language guide avoids a fake universal word blacklist and requires current official context review at publication. Vendored skill count measures integration, not use in a film.

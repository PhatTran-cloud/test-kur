# Storyboard → Motion contract

## Preserve upstream direction
Required upstream fields or equivalents:
- canonical IDs;
- shot interval and beat timing;
- narration/editorial anchors;
- scene geography;
- instance transforms/attachments/visibility;
- object behavior intent;
- focal/attention hierarchy;
- camera keyframes/focus/reveal intent when authored;
- typed transition intent;
- persistent state/callback requirements;
- event intent for VFX.

## Motion may refine mechanics, not meaning
Allowed refinements include interpolation, damping, secondary motion, physically justified reaction timing, collision response, focus execution and transition mechanics.

Not allowed without storyboard revision:
- replacing the hero;
- changing the meaning of a beat;
- moving an object to a different narrative layer for convenience;
- changing object identity;
- inventing a different transition thesis;
- moving the reveal earlier/later enough to change information timing;
- discarding persistent state.

# Integration matrix

This matrix describes capability classes, not external product names.

| Capability | Integration mode | Activation | Forbidden ownership |
|---|---|---|---|
| canonical 3D workflow | full existing base | always | none; this is the base |
| modern Three.js runtime | synthesized guidance | implementation gap | scene direction, final QA |
| GPU/node/compute | synthesized guidance | measured need | global renderer rewrite by default |
| offline procedural geometry | authoring handoff | complex geometry need | final renderer |
| humanoid morphology/rig | domain specialist | human-derived subject | global camera/lighting |
| animal morphology/rig | domain specialist | animal/creature | global camera/lighting |
| attachments/props | domain specialist | worn/held/mounted/contact objects | independent scene loop |
| cinematic motion | temporal specialist | animation/transition | static scene ownership |
| anti-fake-pass | stricter validation | all substantial builds | construction decisions |

All non-base rows are additive and scoped.

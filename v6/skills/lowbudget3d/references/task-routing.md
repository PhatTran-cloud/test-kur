# Capability router

Start with 3dviz-pro-max. Then activate the smallest necessary specialist set.

## Routing table

| Intent | Add |
|---|---|
| ordinary environment/product/architecture already covered well | nothing |
| person/avatar/astronaut | humanoid + attachment + domain QA |
| close-up face/hands | humanoid + stricter hero QA |
| dog/cat/horse/quadruped | animal + domain QA |
| rider + mount | humanoid + animal + attachment |
| clothing/armor/suit/backpack | humanoid + attachment |
| many particles/flocking/compute deformation | GPU routing |
| complex authored geometry | offline authoring handoff |
| animation/transition | cinematic motion |
| current Three.js implementation issue | modern runtime |
| unclear API after routed module is read | technical fallback reference |

Do not load unrelated modules for completeness. Context pollution creates conflict.

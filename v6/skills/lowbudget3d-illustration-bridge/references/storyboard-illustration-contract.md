# Storyboard → Illustration contract

Treat the storyboard as upstream direction, not optional inspiration.

## Required semantics

- IDs are canonical and must survive the pipeline.
- `identity` says what the asset is.
- recognition traits say what must remain visually diagnostic.
- `fabrication.parts` says which parts must remain separately controllable.
- anchors/sockets define downstream attachment.
- variants encode state changes rather than ad-hoc recolors.
- surface regions bind texture/material logic to real construction.
- closest-camera use determines the fidelity floor.
- research findings and uncertainty bound factual claims.
- art direction governs craft; it does not license identity changes.

## Ambiguity protocol

If the storyboard is ambiguous about a design-critical point:
1. do not silently decide;
2. record the ambiguity;
3. choose only a clearly labeled provisional implementation if production must continue;
4. require storyboard revision before claiming conformance.

## No-scene-redesign rule

Illustration may improve craft inside the asset contract but must not:
- add/delete story objects for composition;
- move canonical instances between depth layers;
- invent camera moves;
- rewrite transition intent;
- merge multiple instances into a plate;
- replace a specific researched identity with a generic asset.

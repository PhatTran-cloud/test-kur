# Docs — Reference Library

Three reference documents. Load only what your task needs.

| File | Load When |
|------|-----------|
| `component-registry.md` | Writing a spec or building a composition — need to know available components and their exact props |
| `design-system.md` | Writing a spec — need exact colors, typography minimums, spring configs, layout rules |
| `markup-schema.md` | Running Tag Parser or reviewing tagged output — need to understand what each tag means and its visual mapping |

Do not load all three at once unless you are writing the SPEC_GENERATOR prompt itself.

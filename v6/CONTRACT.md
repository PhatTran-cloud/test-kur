# Mandatory visual storytelling contract
Applies to every genre/film/shot/skill route. Requirements cannot be waived by an implementation skill.
Mandatory session execution: use execution-protocol.md. The latest user-authorized scope and current repo contracts determine which actions may run. Do not invent a pipeline, skip/reorder prerequisites or treat rule/tooling maintenance as permission to generate/render a film. Record actual reads/decisions; never substitute a receipt for real review or authorization.

## Visual argument
Every meaning beat has a metaphor/explanatory analogy with correspondence and limits. Never merely draw nouns from VO. Add useful scale, mechanism, environmental evidence, consequence, contrast, secondary action or reveal. Expressive metaphor is labelled and never presented as evidence.

## Causal acting
Hero behavior is trigger -> action -> consequence. Physical/illustrative/editorial relations state evidence and limits. Objects act/react with force, intention, material and constraint. Semantic/comparison relationships are valid without fabricated physical causality. Event VFX expands source/transport/interaction/world/object/camera/light/aftermath.

## Readable change
Each shot has landmarks for observable object/relationship/scale/viewpoint/knowledge change: before/after, changed variable, frame interval, hold/read time and perception test. Review gaps over four seconds; deliberate holds need attention purpose. This is not an effects quota. Generic particles/orbit/glow/text fading/jitter cannot satisfy all change.

## Living world and camera
Each shot names meaningful FG/MG/BG depth/information, background context/evidence/consequence and secondary acting. Each visible instance gets active/reactive/passive/optical/camera-induced/motivated-stillness treatment. Protect hero/secondary/ambient/suppressed attention; do not jitter every element.
Camera in/action/out states known/hidden/revealed information. Held cameras can reveal through staging/focus/action. Arbitrary zoom/orbit is insufficient. Lens/framing/height/scale/focus serve discovery. Shake is bounded event response.

## Original art and handoffs
Each film authors palette roles, shape/silhouette/edges, typography, material/light/depth, camera/motion/VFX/transition grammar and recurring motifs. Choose 2D/2.5D/3D/hybrid by purpose; reuse mechanisms, not reference skins/code/artwork.
Every handoff carries outgoing action or meaning into incoming state. Declare type/cause/invariant and subject/motion/scale/shape/light/sound/semantic continuity. Semantic cuts need no fake shared object. Fade needs reason; never rotate transition effects mechanically. Preserve identity/geography/state/momentum/residue where relevant.

## Units and execution
No chapter hierarchy. Scene/shot expresses space/editorial structure; claim/beat/action/landmark expresses explanation. Cross-reference many-to-many; SB/ASR sections are not cuts. Runtime consumes explicit IDs/actions/states, never nouns/titles/kind/chapter.
Storyboard owns WHAT/WHERE/WHY/WHEN; assets editable construction; motion/VFX HOW within constraints. Preserve IDs, read repo/stage/skill rules and log decisions. Provisional VO cannot pass production. Word anchors and authored offsets are separate; absolute frame/seed reconstructs state.

## Anti-fake-pass
Completeness proves structure, not beauty/comprehension. No self-scored literalness metric establishes quality. Build/render gates need actual evidence, observations, reviewer, unresolved issues and current content hashes. Unknown remains unknown. Full render requires reviewed upstream intent and explicit existing authorization for that film; never auto-render on pipeline completion.

# Original art systems for arbitrary topics
Develop identity; do not impose one film's palette/asset list/styleframe count on every genre. Write question/thesis/emotional arc/tactile idea, propose three materially distinct systems, select with reasons and test demanding subjects wide/close/in action.

Define palette roles, silhouette/shape ratios, edge craft, type roles, surface/material scale, emitter/receiver light, atmosphere, depth/compositing, camera/motion/VFX/transition/sound grammar. Motifs transform/return rather than sit as pasted overlays. Diagrams/characters/environment/effects share recognizable invariants.

## Kage reference principles
Kage's prompt describes continuous spatial camera, layered foreground, atmospheric depth, editorial type and eased handoffs. Learn composition/attention; its scroll controls, old runtime, temple palette and web layout are not video requirements. Adapt to narration and deterministic frames. README grants no reuse license for original code/art; do not vendor them.
Sources: https://github.com/MengTo/kage and https://raw.githubusercontent.com/MengTo/kage/main/PROMPT.md. X profile unavailable during review; no unseen post is evidence. Kurzgesagt informs reasoning/clarity, not copied characters/palettes/layouts.

## Craft and coverage
3D serves scale/contact/material/volume/travel; authored vectors serve diagrams/symbols/precise information; 2.5D needs honest editable depth/parallax. Preserve light/edge/type/motion across media. Primitives are scaffolds, not finished fidelity-sensitive subjects.
Styleframe coverage follows hard requirements: environment/depth, identity, information diagram, mechanism/change, transition pair, material/VFX if applicable. Count follows coverage. Test identity before decoration, target phone-size readability, closest-camera details, intentional crop versus accidental clipping, diagnostic/no-post light. Bloom/grain cannot rescue wrong construction.

art-system.json stores identity/candidates/grammar/motifs/coverage. asset-bible.json stores canonical parts/states/behavior. Every shot references same approved system/tokens.

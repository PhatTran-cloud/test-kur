# Writing a visual-first explainer script

This is the v6 editorial guide for arbitrary topics and genres. It keeps language accurate, visual and context-aware without flattening the story. Platform review considers presentation and context; a keyword list does not guarantee distribution.

## Start with the editorial spine

Before drafting lines, write:

```text
viewer_question:
visual_thesis:
promise:
payoff:
emotional_arc:
final_reframe:
```

The thesis is an argument, not a topic label. “A city uses water” is a topic. “An ordinary tap connects a person to an invisible network of dependencies” is a thesis that can govern images, motion, and transitions.

## Write claims before metaphors

Separate each line into:

1. factual claim;
2. evidence or uncertainty;
3. emotional or rhetorical framing;
4. expressive metaphor.

Metaphor may add clarity, scale, or feeling. It must never be presented as scientific evidence. Approximate dates, contested mechanisms, and compressed timelines need an uncertainty note in the claim ledger.

## The visual beat test

A beat changes understanding, state, scale, viewpoint, or emotion. For every beat answer:

```text
What was true at the start?
What action changes it?
What is visibly true at the end?
Why does the viewer need this shot?
What useful detail exists outside the narration?
What causes the next beat?
```

If the answer is only “show the noun,” rewrite the beat.

## Visual metaphor patterns

Use the pattern that clarifies the claim, then adapt it to the approved art system:

| Pattern | Useful for |
|---|---|
| pressure and release | accumulation, collapse, ignition, social tension |
| relay or inheritance | matter, genes, knowledge, technology |
| nested worlds | scale changes and hidden mechanisms |
| chain reaction | causal systems and consequences |
| transformation of one object | continuity across time |
| threshold and crossing | evolution, discovery, migration, change |
| balance and tipping | competing forces or feedback |
| searchlight/reveal | mystery, evidence, hidden structure |
| landscape as instrument | climate, ecology, atmosphere, sound |
| character goal and obstacle | human stories, systems, history |

Metaphor selection must be logged so an implementation agent cannot silently replace it with a literal illustration. Define correspondence and limits: which properties map, which do not. A metaphor may make an idea felt without pretending to simulate it.

## Hooks by genre

Hooks create a question or contradiction immediately. They should show an event or visual problem in the first frame while leaving the explanation open.

| Genre | Hook families |
|---|---|
| science | impossible scale, hidden ingredient, consequence first, matter-to-person loop |
| history | one object crossing eras, a present-day trace, a moment before the turn |
| nature | environment reacts before the cause is named, sensory immersion, invisible network reveal |
| technology | invisible system becomes physical, failure already underway, one input changes a world |
| business/economy | consequence before mechanism, counterintuitive comparison, ordinary object under pressure |
| mystery | evidence appears in layers, misleading surface, delayed identity reveal |
| human story | gesture before biography, goal and obstacle, memory/object callback |
| broad explainer | question hold, scale flip, before/after transformation, countdown/compression |

Develop at least three distinct candidates before choosing: visual event, question, emotional invitation, promised payoff and fit to audience/format. Track the selected family across a series to avoid repeating one formula. Rotate meaning, not arbitrary entrance effects. Do not confuse a large title with a hook. An atmospheric hook is valid when it reveals a concrete mystery; gratuitous shock or instant explosions are not mandatory.

### Candidate variations

| Family | Story move | Short-form variant | Long-form variant |
|---|---|---|---|
| personal embodiment | ordinary gesture contains a hidden system | action first, one mystery | gesture returns as final reframe |
| contradiction | visible evidence challenges expectation | two incompatible states in one world | investigate why expectation failed |
| consequence first | show a changed world before the cause | visible result -> rewind | result becomes a question carried through mechanisms |
| mystery object | identity/function stays hidden | close detail -> reveal | same object appears as a clue across scenes |
| scale flip | familiar view belongs to a larger/smaller system | pull out or push through | multiple justified changes of instrument/viewpoint |
| sensory immersion | environment acts before explanation | one revealing movement | discover an ecosystem of signals gradually |
| system failure | one constraint destabilizes relations | failed action -> hidden dependency | examine alternatives and recovery |
| goal/obstacle | an actor wants a result but something resists | gesture -> blocked action | escalating choices with consequences |
| time compression | changing object makes duration intelligible | fast transformation with landmark holds | compression is explicitly framed and later unpacked |
| visual loop | ending physically/semantically returns to opening | final action completes first frame | callback gains new meaning after explanation |

## Narrative progression without a fixed formula

Arrange beats as question -> attempt/evidence -> complication -> mechanism -> consequence -> reframe, or another arc suited to the subject. Use “because / therefore / but” relations to test progression; if everything only connects by “and then,” look for the missing question or causal relationship. History/fiction may use editorial succession rather than unsupported physical cause.

Re-hook with new evidence, scale, consequence or reversal. Do not flash a color or add an effect merely to reset attention. Alternate observation, explanation, uncertainty and payoff so fact density does not bury action. Preserve a recurring subject/motif/constraint when it supports continuity. Allow pauses for the viewer to read a change. End by answering the promised question and transforming an earlier image, not listing facts again.

## Script-to-direction working table

For each line or group of lines record exact VO, claim IDs, viewer knowledge before/after, metaphor/limits, hero trigger/action/consequence, relational evidence, background expansion, secondary behavior, camera reveal, readable landmark and outgoing cause. One sentence may span shots; many lines may share one transforming world. Do not insert camera jargon into spoken narration.

## Worked example: “The rainforest is never truly silent.”

Literal failure: forest picture plus the same line as a title. Instead develop the idea as a hidden network of activity:

- Foreground: large leaves partially occlude the viewpoint; a small contact moves their edges.
- Midground: a stem reacts to a perched insect or passing creature, so motion has a visible source.
- Background: layered mist, distant silhouettes and small pulses carry depth/activity; visualized sound is labelled expressive.
- Camera: pass through foliage to reveal signals that could not be seen from the opening viewpoint.
- Reveal: points resolve into eyes, insects or droplets; do not imply every insect glows or every dot is a real biological signal.
- Secondary: a landing insect bends a leaf while another distant actor crosses a gap without stealing focus.
- State/knowledge: apparent stillness -> identifiable simultaneous activity, with a held readable reveal.
- Transition: follow one revealed actor/light correspondence into an authored macro view, preserving its identity/motion or explicitly declaring a semantic match.

This expansion clarifies the idea beyond the words. A tree shaking “for no reason” or a metaphor presented as biological fact would weaken it. Record limits and ground actual behavior in the claim ledger.

## Scene writing pattern

Write each scene card as a small film:

```text
arrival: what persists from the prior scene?
foreground: what gives depth or blocks/reveals attention?
midground: who/what acts and against what?
background: what evidence or consequence is visible?
camera_in: what is initially hidden?
hero_action: trigger -> action -> consequence
secondary_actions: at least one meaningful parallel behavior
state_change: before -> after
camera_out: what carries forward?
transition: why this next scene is born from this action
```

## Platform-safe language

Use plain, accurate language. Avoid graphic detail, glorification, shock framing, hateful or demeaning language, instructions for harm, and sensational wording that adds no educational value. For impacts, extinction, death, or disaster, prefer non-graphic scientific description and show forces, environments, traces, or aftermath rather than bodily damage. Do not use euphemisms intended to evade moderation systems. Keep a dated policy review record; platform rules change.

The reviewer checks video, audio, title, thumbnail, description and tags together. Keep source/date/reviewer/decision records in production.json. Distinguish community rules, recommendation eligibility, age restriction and advertising suitability. Educational context helps but is not a universal exemption. Official YouTube advertiser guidance explicitly considers context and all presentation surfaces: https://support.google.com/youtube/answer/6162278?hl=en. Recheck Meta/TikTok official rules at publication; their detailed pages were unavailable in this research session.

## Script acceptance tests

- The first beat contains a concrete question, contradiction, or visual event.
- Every major claim maps to a visual metaphor or mechanism.
- No adjacent beats repeat the same framing and motion without a narrative reason.
- The ending reinterprets an earlier visual or action.
- The script contains enough pauses for action to be readable.
- Uncertainty and metaphor are labelled in the claim ledger.

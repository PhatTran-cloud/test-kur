# v6 runtime primitives

`runtime.ts` executes canonical IDs and absolute-frame tracks. `evaluateFrame` reconstructs persistent actor channels by evaluating prior authored events, so seeking backwards or directly to a later shot does not depend on playback. `executeShot` refuses unknown bindings; no noun/kind/chapter fallback.

This is infrastructure, not a finished scene renderer. Topic-specific authored assets, camera rigs, physical/illustrative mechanisms, metaphors, landmark execution, event VFX and transition rendering still belong to an approved production packet. Scalar/vector tracks do not replace crafted rigs. Use analytic/custom deterministic evaluators when the behavior needs them; retain IDs/time and inspect their endpoints.

The guarded build validator checks declared files/bindings/evidence; it cannot prove that arbitrary source implements a declared behavior. Visual/encoded and nonsequential seek review remains mandatory. v5 imports are untouched.

# v6 semantic tag schema

Tags are linguistic evidence only. They never choose components, impose cuts, determine art or replace a meaning beat. Read v6/CONTRACT.md and manifest-guide.md.

## Basic vocabulary

| Tag | Observable signal |
|---|---|
| EM | named concept/contrast/punchline; minimum phrase <=5 words |
| E | explicit failure/problem/negative outcome |
| STAT | quantity, unit, ratio and context; preserve exact spoken value |
| SB | paragraph/topic boundary; NOT a scene boundary |
| LIST | three or more syntactically parallel items |
| QUOTE | attributed quotation; keep attribution and wording |
| CLOSE | closing reframe or final statement |
| META | relation/process/structure/visual concept with type and subtype |

## Anchor identity

Canonical semantic IDs include a unique occurrence index, not truncated text. Duplicate words must still have distinct IDs. Director mapping can combine/separate tags; content count is not a beat-density target. Aligned frame anchors derive from actual word indices/timestamps/configured FPS. If unresolved, mark provisional.

## Direction ownership

No automatic EM shine, E glitch, STAT count-up or SB fade. Quantity may need scale/relationship/time/comparison; director chooses the metaphor, mechanism and action from claim evidence. Keep taxonomy independent of medium and component implementation.
